캐릭터 관계도 사용법

마우스 & 화면 이동

  • • 빈 캔버스 더블 클릭: 새 캐릭터 추가
  • • 휠 클릭 + 드래그 또는 Space + 드래그: 화면 이동
  • • 포트(동그라미) 우클릭: 관계선 삭제 옵션
  • • 캐릭터 Shift + 클릭: 다중 선택

단축키

  • • Del / Backspace: 선택한 노드/관계선 삭제
  • • Ctrl + Z: 실행 취소
  • • Ctrl + Y: 다시 실행

스토리 분기 사용법

마우스 & 분기 연결

  • • 빈 캔버스 더블 클릭: 새 분기(노드) 추가
  • • 선택지 포트(동그라미)를 드래그해서 다음 노드 상단에 연결
  • • 연결선 클릭 후 삭제 또는 포트 우클릭: 해당 연결선 끊기
  • • 휠 클릭 + 드래그 또는 Space + 드래그: 화면 이동

변수 및 조건 설정 (고급)

  • • 실행 변수: has_key = true
    (해당 노드 도달 시 변수 활성화)
  • • 출현 조건: 선택지에 has_key 등 변수명 입력 시 히든 분기로 설정됩니다.
