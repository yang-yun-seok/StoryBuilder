캐릭터 관계도 사용법

마우스 & 화면 이동

  • • 빈 캔버스 더블 클릭: 새 캐릭터 추가
  • • 우클릭 드래그 · 휠 클릭 드래그 · Space + 드래그: 화면 이동
  • • 휠 스크롤: 확대/축소  |  Shift + 휠: 좌/우 이동  |  Alt + 휠: 상/하 이동
  • • 포트(동그라미) 우클릭: 관계선 삭제 옵션
  • • 캐릭터 Shift + 클릭: 다중 선택

단축키

  • • Del / Backspace: 선택한 노드/관계선 삭제
  • • Ctrl + Z: 실행 취소  |  Ctrl + Y: 다시 실행
  • • Ctrl + S: JSON 백업 다운로드
  • • 상단 키보드 아이콘에서 단축키를 원하는 키로 변경할 수 있습니다.

스토리 분기 사용법

마우스 & 분기 연결

  • • 빈 캔버스 더블 클릭: 새 분기(노드) 추가
  • • 선택지 포트(동그라미)를 드래그해서 다음 노드 상단에 연결
  • • 우측 인스펙터의 연결 대상 드롭다운 또는 캔버스 지정 버튼으로도 연결 가능
  • • 연결 지정 중 Esc 또는 우클릭: 연결 모드 취소 (기존 연결 유지)
  • • 연결선 클릭 후 삭제 또는 포트 우클릭: 해당 연결선 끊기
  • • 우클릭 드래그 · 휠 클릭 드래그 · Space + 드래그: 화면 이동
  • • 휠 스크롤: 확대/축소  |  Shift + 휠: 좌/우 이동  |  Alt + 휠: 상/하 이동

단축키

  • • Del / Backspace: 선택한 노드/연결선 삭제
  • • Ctrl + S: JSON 백업 다운로드
  • • Ctrl + D: 선택한 노드 복제
  • • Ctrl + Z: 실행 취소  |  Ctrl + Y: 다시 실행
  • • 상단 키보드 아이콘에서 단축키를 원하는 키로 변경할 수 있습니다.

변수 및 조건 설정 (고급)

  • • 실행 변수: has_key = true
    (해당 노드 도달 시 변수 활성화)
  • • 출현 조건: 선택지에 has_key 등 변수명 입력 시 히든 분기로 설정됩니다.

단축키 설정

변경할 항목의 키 지정 버튼을 누른 뒤 원하는 키를 입력하세요. `Esc`로 입력 대기 취소.

마우스 제스처(고정): 휠=확대/축소, Shift+휠=좌/우 이동, Alt+휠=상/하 이동
